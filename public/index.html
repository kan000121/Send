      使い方
      
      
    
      
    
      
      
      
        
      3ステップで一斉送信できます
      
        
      同じメッセージを、複数のチャンネルや DM にまとめて送れます。
      
        
      
          
      ① 送信者誰として送るか
      
          →
          
      ② メッセージ本文を書く
      
          →
          
      ③ 宛先送り先を選ぶ
      
          →
          
      確認して送信送信後の取り消しも可
      
        
      
        
      「次へ」ボタン、← → キー、スワイプでページを移動できます。この説明は右上の ? 使い方 からいつでも開けます。
      
      
      

      
      
        
      1送信者を選ぶ
      
        
      画面上部の切り替えで、誰の名前で投稿するかを選びます。
      
        
      
          
      
            
      個人として送信 （標準）
      
            
        
              
      • あなたの名前とアイコンで投稿されます
        • 
              
      • 送れるのは、あなたが参加しているチャンネル
        • 
              
      • ユーザートークン（xoxp- で始まる）が必要です
        • 
            
      
          
      
          
      
            
      Bot として送信
      
            
        
              
      • Bot の名前とアイコンで投稿されます
        • 
              
      • 送れるのは、Bot が参加しているチャンネル
        • 
              
      • 管理者がサーバーに設定済みなら、トークンの入力は不要です
        • 
            
      
          
      
        
      
      
      

      
      
        
      ユーザートークンの入手方法
      
        
        
          
      1. ブラウザで https://api.slack.com/apps を開き、社内の送信用アプリを選びます。どのアプリか分からない場合は、管理者に確認してください。
        2. 
          
      2. 左のメニューから OAuth & Permissions を開きます。
        3. 
          
      3. User OAuth Token（xoxp- で始まる文字列）の Copy を押します。トークンが表示されていない場合は、先に Install to Workspace を押してください。
        4. 
          
      4. この画面の「ユーザートークン」欄に貼り付けて 確認 を押します。「✓ ○○として送信できます」と表示されれば準備完了です。
        5. 
        
      
        
      トークンはパスワードと同じです。チャットやメールで他の人に共有しないでください。
      
        
      team_id は通常空欄で構いません。複数のワークスペースを使う Enterprise Grid の場合のみ、管理者に確認してください。トークンはサーバーに保存されないため、ページを再読み込みしたら再入力が必要です。
      
      
      

      
      
        
      Bot として送る場合
      
        
        
          
      • 管理者がサーバーに Bot トークンを設定している場合は、Bot として送信 を選ぶだけで使えます（「✓ Bot ○○ で送信できます」と表示されます）。
        • 
          
      • 自分で入力する場合は、前のページと同じ OAuth & Permissions にある Bot User OAuth Token（xoxb- で始まる）を貼り付けて 確認 を押します。
        • 
          
      • 公開チャンネルは、宛先の下にある「Bot が自動で参加する」をオンにすれば、Bot が未参加でも送れます。
        • 
          
      • 非公開チャンネルに送るには、そのチャンネルで /invite @Bot名 を実行して Bot を招待しておいてください。
        •

      • 本文（必須）：チャンネルや DM に投稿されるメッセージです。
        • 
          
      • 案件概要（任意）：本文へのスレッド返信として、コードブロックで投稿されます。``` で囲む必要はありません。
        •

      3宛先を選ぶ
      
        
        
          
      • チャンネル：チェックを入れたチャンネルに投稿します。絞り込み欄で検索し、表示中をすべて選択 でまとめて選ぶこともできます。
        • 
          
      • チャンネルごとに、メンションの種類を選べます。
        • 
        
      
        
      
          
      
            # general
            
          
      
          @channel：チャンネル全員に通知 ／ 指定ユーザー：選んだ人だけにメンション
        
      
        
        
          
      • DM（任意）：選んだ人それぞれに、個別の DM として送ります。
        • 
          
      • 選択中のみ表示 にチェックを入れると、選んだ宛先だけを確認できます。
        • 
        
      
      
      

      
      
        
      確認して送信
      
        
        
          
      1. 画面下部の 内容を確認して送信 を押します。
        2. 
          
      2. 確認画面で宛先と本文を見直し、送信する を押します。@channel を含む場合は注意が表示されます。
        3. 
          
      3. 「送信結果」に、宛先ごとの成功・失敗が表示されます。
        4. 
        
      
        
      失敗したときのよくある原因
      
        
        
          
      • 「チャンネルに参加していません」：チャンネルに参加するか、Bot を招待してください。
        • 
          
      • 「トークンが無効です」「失効しています」：トークンを入手し直して、もう一度 確認 してください。
        • 
          
      • 「権限（スコープ）が不足しています」：アプリの設定が必要です。管理者に連絡してください。
        • 
        
      
      
      

      
      
        
      送信を取り消す
      
        
        
          
      • 画面下部の 送信を取り消す を押すと、直前の送信をまとめて削除できます。
        • 
          
      • スレッドに付けた案件概要も一緒に削除されます。他の人が付けた返信は残ります。
        • 
          
      • 一部の削除に失敗した場合は、もう一度押すと残りを再試行します。
        • 
        
      
        
      取り消せるのは、同じトークンで送った直前の 1 回だけです。サーバーが再起動すると取り消せなくなるため、間違いに気づいたらすぐに取り消してください。
